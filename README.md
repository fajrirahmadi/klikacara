# Klik Acara

## Overview
Klik Acara is a mobile application designed to facilitate event-related services, including:
- Requesting event services
- Promoting events
- Renting event equipment
- Catering rental services
- And more

This application is built using **Kotlin** and follows the **Model-View-Presenter (MVP)** architecture for maintainability and scalability.

## Features
- **Event Requests:** Users can request assistance for their events.
- **Event Promotion:** Promote upcoming events with ease.
- **Equipment Rental:** Rent event-related equipment conveniently.
- **Catering Services:** Connect with catering providers for event needs.
- **User Authentication:** Secure login and user authentication.
- **Notifications:** Stay updated with event-related notifications.

## Tech Stack
- **Programming Language:** Kotlin
- **Architecture Pattern:** MVP (Model-View-Presenter)
- **Networking:** Retrofit
- **Database:** Room Database
- **Dependency Injection:** Dagger/Hilt
- **UI Components:** Jetpack Components, ViewBinding
- **Push Notifications:** Firebase Cloud Messaging (FCM)

## Installation
1. Clone the repository:
   ```sh
   git clone https://github.com/your-repo/klik-acara.git
   cd klik-acara
   ```
2. Open the project in **Android Studio**.
3. Sync Gradle files and install necessary dependencies.
4. Run the application on an emulator or physical device.
